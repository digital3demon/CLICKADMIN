# Click Lab — сканер в заказ

## Для админов / обычных пользователей

Один файл: **ClickLab-Scanner.exe** (в zip на рабочем столе разработчика: `ClickLab-Scanner-Watcher.zip`).

1. Скопируйте exe на ПК у сканера.
2. Запустите — откроется окно с настройками и пояснениями:
   - **Папка сканера** — куда устройство сохраняет фото
   - **Адрес CRM** — ссылка из браузера
   - **API-ключ** — из CRM → Конфигурация → API (создаёт владелец)
   - **Запускать вместе с Windows** — программа сама откроется после включения ПК и сразу начнёт ждать сканы
3. «Сохранить настройки» → «Начать работу».

Всё хранится в `settings.json` рядом с exe. Редактировать файлы вручную не нужно.
